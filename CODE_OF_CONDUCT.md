# Code of Conduct

This project aims to keep technical collaboration respectful, focused, and useful.

## Expected behavior

Participants should:

- discuss ideas and code, not attack people;
- give actionable technical feedback;
- assume mistakes can be corrected;
- respect different levels of experience;
- avoid harassment, discrimination, threats, doxxing, spam, and deliberately disruptive behavior;
- keep security-sensitive information out of public threads when private disclosure is appropriate.

## Maintainer actions

The maintainer may edit, hide, lock, or remove content that is abusive, unsafe, off-topic, spam, or harmful to the project, and may restrict participation when necessary.

## Scope

This applies to project-controlled spaces, including issues, pull requests, reviews, and discussions related to this repository.

For security disclosures, use the process in [SECURITY.md](SECURITY.md).
