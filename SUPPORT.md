# Support

## Where to ask

Use a GitHub issue when you have:

- a reproducible updater bug;
- an installation or scheduler problem caused by this project;
- a feature request;
- a compatibility problem with a supported operating system.

Before opening an issue, check existing issues and include the information requested by the issue form.

## What to include for bugs

Useful details:

- operating system and version;
- Amnezia VPN version;
- updater version or commit;
- how the updater was installed;
- exact steps to reproduce;
- expected and actual behavior;
- relevant logs or CLI output with sensitive data removed.

## Upstream list problems

If a domain is missing from or incorrectly included in the source list itself, that is normally an upstream data issue rather than an updater bug. The current source is:

- https://github.com/lib4u/amnezia-tunneling-ru

This repository is responsible for safely consuming the list, not maintaining its contents.

## Security issues

Do not disclose vulnerability details in a normal support issue. Follow [SECURITY.md](SECURITY.md).

## Scope

This is an independent, unofficial project and is not an Amnezia VPN support channel.
